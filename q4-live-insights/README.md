# Question 4: Live Insights and Nudges

This folder contains a streaming simulation that analyzes a call chunk by chunk and emits nudges in near real time.

## What it demonstrates

- live-style transcription chunking
- lightweight speaker separation
- topic shift tracking
- signal detection
- compliance and missed-opportunity nudges
- duplicate suppression
- latency reporting
- approximate false-positive analysis

## How to run

```powershell
python .\src\cli.py demo
python .\src\cli.py benchmark
```
