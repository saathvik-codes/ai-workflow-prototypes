# Question 3: Native-Language Voice Bots

This folder contains two localized voice-bot simulations:

- Philippines insurance/bancassurance bot
- Indonesia multifinance/consumer finance bot

## What it demonstrates

- natural code-switching
- market-specific terminology
- language-aware fallback
- localized reminders and qualification language

## How to run

```powershell
python .\src\cli.py test
python .\src\cli.py run ph
python .\src\cli.py run id
```
